# 🧪 Molecular Geometry Lab — Introdução à Geometria Molecular

🔗 **[Acessar o Projeto](https://carlosguedes-dev.github.io/molecular-geometry-lab/)**

## 📌 Sobre o Projeto
Uma aplicação web interativa 3D para o estudo de Geometria Molecular. O projeto permite explorar, visualizar e construir modelos moleculares em três dimensões, cobrindo as **5 geometrias fundamentais** previstas pela teoria VSEPR: Linear, Trigonal Planar, Tetraédrica, Pirâmide Trigonal e Angular.

O objetivo do laboratório é fornecer uma ferramenta imersiva que facilita a compreensão espacial de moléculas e suas estruturas.

## 🚀 Tecnologias Utilizadas
- **HTML5** Semântico
- **CSS3** (Variáveis CSS, Flexbox, Grid e Design Responsivo Premium com Glassmorphism)
- **JavaScript Vanilla** (Módulos ES6 para lógica da interface)
- **Three.js** (Renderização 3D, interações, nuvens eletrônicas e materiais avançados)

## ✨ Principais Funcionalidades
- **Modo Explorar**: Interaja com 15 moléculas reais em 3D. O viewport permite arrastar para rotacionar livremente e dar zoom via scroll.
- **Modo Construir**: Monte sua própria molécula, escolhendo a geometria e os átomos ligantes ao átomo central. O modelo 3D é atualizado em tempo real.
- **Análise Visual Avançada**: Ative overlays e visualizações extras, incluindo Nuvem Eletrônica, Pares de Elétrons Isolados e Anotações estruturais.
- **Design de Alta Performance (UI/UX)**: Uma interface "premium", com tela de loading cinematográfica, feedbacks visuais precisos e responsividade completa para Desktop e Mobile.
